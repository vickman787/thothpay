# ThothPay

**Every citation pays its author.**

A pay-per-citation AI research terminal on Celo. Ask a question, watch the agent read the registered corpus, and see stablecoins land in creators' wallets the moment their work gets cited. No subscriptions, no scraping — just receipts.

## The concept

Current AI models are trained on millions of articles while original authors receive nothing. ThothPay inverts this: when the agent synthesizes an answer from a registered knowledge base, it cites its sources and instantly pays each cited creator a citation fee in stablecoins on Celo.

- **For researchers:** connect a wallet, set a budget, ask. You only pay for citations actually used.
- **For creators:** verify ownership, register your work, set your own citation price, earn on every citation.
- **For agents:** a first-class x402 endpoint so other autonomous agents can call ThothPay and settle payments in one round trip.

## Track

Celo **Agents at Work** hackathon — primary track **Value Moved**, with the **Best Stablecoin Adoption** sub-bounty via x402 settlement.

## Stack

- Celo mainnet (L2, cheap fees, fee abstraction)
- Stablecoins: cUSD (Mento) / USDC / USDT / USAT
- x402 for agent-to-agent payment
- ERC-8021 attribution tags for hackathon credit
